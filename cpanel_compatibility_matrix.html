२. cPanel वर अपलोड करताना सर्वात महत्त्वाची खबरदारी (How to Upload):
बऱ्याच वेळा लोक संपूर्ण प्रोजेक्टचा फोल्डर (node_modules, src/, package.json सह) cPanel वर अपलोड करतात, ज्यामुळे साईट एरर दाखवते. खालील सोपी व योग्य पद्धत वापरा:
१. बिल्ड तयार करा

आपण प्रोजेक्टचा प्रोडक्शन बिल्ड आधीच तयार केला आहे (npm run build).

२. dist फोल्डर

प्रोजेक्ट फोल्डरमध्ये dist/ तयार आहे. त्यात index.html, assets/ आणि इमेज आहेत.

३. cPanel File Manager

cPanel लॉगिन करा ➔ File Manager उघडा ➔ public_html/ फोल्डरमध्ये जा.

४. फक्त dist अपलोड करा

dist फोल्डरच्या आतल्या सर्व फाईल्स तिथे अपलोड करा (किंवा dist चा ZIP करून Extract करा).

३. Relative Path आधीच कॉन्फिगर आहे (base: './'):

आपण vite.config.js मध्ये आधीच base: './' सेट केलेले आहे. त्यामुळे तुम्ही ही साईट मुख्य डोमेनवर टाका (उदा. https://yourdomain.com/) किंवा सब-फोल्डरमध्ये टाका (उदा. https://yourdomain.com/cyber-shield/) — कोणत्याही पाथवर एकही CSS, फॉन्ट किंवा इमेज तुटणार नाही, सर्व काही पहिल्याच प्रयत्नात व्यवस्थित चालेल!
